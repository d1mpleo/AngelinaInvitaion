# Запрошення для Ангеліни 💌

Статична сторінка без бекенду: `index.html` + `style.css` + `app.js` + **`config.js`**.
Усі тексти, питання та варіанти відповідей редагуються тільки в `config.js`.

## Як захостити на GitHub Pages (через Actions)
1. Створи репозиторій на GitHub (на безкоштовному плані для Pages він має бути **public**).
2. Завантаж усі файли в корінь репозиторію, разом з папкою `.github/`. Гілка має називатися `main`.
3. Відкрий **Settings → Pages → Build and deployment → Source** і вибери **GitHub Actions**.
4. Після пуша в `main` запуститься workflow `Deploy to GitHub Pages` (вкладка **Actions**). Через хвилину сайт буде тут:
   `https://ТВІЙ_НІК.github.io/НАЗВА_РЕПО/`

Кожна зміна в `main` перепублікує сайт автоматично. Змінити текст можна прямо на github.com: відкрий `config.js`, натисни ✏️, збережи (commit).

## Що змінювати в config.js
- `intro`, `finish`, `messageGreeting`: тексти на початку та в кінці
- `daysAhead`: скільки днів показувати (дати рахуються автоматично від завтра)
- `questions`: додавай, видаляй і міняй питання. Поля: `id`, `label`, `emoji`, `title`, `sub`, `options`; `multi: true` для вибору кількох; `ownOption` для варіанта зі своїм текстом; `type: "text"` для вільного поля
- `contactUrl`: наприклад `https://t.me/твій_нік`, відкриється після копіювання відповідей

## Важливо
Сайт публічний, тому не пиши в ньому нічого приватного. Відповіді на сервер не відправляються: Ангеліна копіює їх і надсилає тобі сама.
